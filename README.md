# Bunny's Brilliant Path

Create a modern, premium educational mobile application called "Bunny" for the Sudanese curriculum.

Design Style:
- Clean, minimal, modern UI.
- Soft calming blue as the primary color (#4F8EF7 or similar).
- White backgrounds with subtle light blue gradients.
- Rounded corners (20–24px).
- Soft shadows and smooth animations.
- Friendly, premium, and distraction-free.
- Fully supports Arabic (RTL).

Brand Identity:
- Keep Bunny (the rabbit mascot) consistent across all screens.
- Bunny should appear as a friendly study companion that motivates students.
- The design should feel like a premium app made in 2026.

Main Features:
- Login & Sign Up.
- Choose educational stage.
- Choose grade.
- Home dashboard.
- Subjects.
- Units.
- Lessons.
- Lesson explanation.
- Smart summaries.
- Flashcards.
- AI-generated quizzes.
- Progress tracking.
- Daily study planner.
- Achievements and rewards.
- AI Study Assistant (Bunny AI).
- User profile.
- Settings.

Navigation:
Bottom Navigation:
🏠 Home
📚 Curriculum
🤖 Bunny AI
📈 Progress
👤 Profile

UI Requirements:
- Large modern cards.
- Beautiful blue icons.
- Premium typography.
- Smooth page transitions.
- Glassmorphism effects where appropriate.
- Consistent spacing.
- Mobile-first design.
- Professional onboarding screens.
- Empty states with Bunny illustrations.
- Loading animations.
- Dark mode support.

Student Experience:
The app should feel motivating, calm, intelligent, and easy to use. Every screen should guide students naturally without clutter. Focus on helping students learn through summaries, flashcards, quizzes, and AI assistance.

Generate a complete, production-quality mobile app with a beautiful, consistent design system and realistic sample content.
